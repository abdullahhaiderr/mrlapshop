# Mr LapShop — Owner checklist for the next development stage

The following details are needed before the live backend and admin dashboard can be completed. Do not send passwords, private API keys, bank credentials or customer personal data in chat.

## 1. Choose the backend architecture

- [ ] Confirm Railway PostgreSQL + Cloudflare R2, Appwrite Cloud, or a self-hosted VPS.
- [ ] Confirm the monthly budget range.
- [ ] Create the development account/project only after choosing the architecture.
- [ ] Share only the non-secret project URL/identifier. Secrets should be entered locally in `.env.local` and never pasted into the public repository.

## 2. Customer video testimonials (independent of dashboard)

- [ ] Send individual YouTube video URLs, not only the channel URL.
- [ ] Provide the preferred title/caption for each video.
- [ ] Confirm that customers agreed to have their videos displayed on the shop website.
- [ ] Tell us whether each video is a normal landscape video or a vertical YouTube Short.

## 3. Product inventory template

For every laptop/accessory listing, prepare:

- [ ] Brand and category.
- [ ] Exact product title/model/series and unique unit/SKU if applicable.
- [ ] Condition: New, Used or Open Box only.
- [ ] Processor, generation/model, RAM capacity/type, storage capacity/type, screen size/resolution, GPU and operating system where relevant.
- [ ] Cosmetic grade and battery condition for used/open-box laptops where applicable.
- [ ] Selling price in PKR and optional previous/list price.
- [ ] Quantity/stock status.
- [ ] Warranty duration and product-specific warranty terms.
- [ ] Product description and key highlights.
- [ ] Original product photos that the shop has permission to use.

Accessories can use a category-specific specification form rather than laptop-only fields.

## 4. Delivery, payment, return and cancellation rules

- [ ] Cities served and whether delivery is nationwide or limited to selected cities.
- [ ] Delivery fee by city/zone and estimated delivery time.
- [ ] Whether the buyer can pay the full amount on delivery, Rs. 1,000/Rs. 2,000 advance, or 20% advance; specify when each option is allowed.
- [ ] Shop-pickup process and opening hours for collection.
- [ ] Bank-transfer payment confirmation process. Bank details should later be entered privately in the dashboard/settings, not shared in this checklist.
- [ ] Confirm the final cancellation fee (the earlier Rs. 1,000–1,500 range is not yet an approved policy).
- [ ] Exact return, replacement, refund and cancellation eligibility, time limits and condition requirements.
- [ ] Confirm whether return/refund rules differ by product category or condition.

## 5. Warranty and technical handover

- [ ] Confirm warranty wording and exceptions for New, Used and Open Box units.
- [ ] Confirm who pays shipping for warranty claims and where customers bring/send devices.
- [ ] Confirm whether warranty cards/invoices will be uploaded or recorded for each item.
- [ ] Decide which setup tasks are included by default (OS, drivers, system updates) and which software installs require an additional charge or customer licence.
- [ ] Confirm whether battery health, screen condition and cosmetic grade must be shown on every used unit.

## 6. Reviews, offers and notifications

- [ ] Decide the verified-purchase rule for written reviews (recommended: reviews can be submitted only for an order marked delivered).
- [ ] Approve the review form fields and moderation process.
- [ ] Confirm promo-code rules: percentage/fixed amount, dates, usage cap, minimum order, eligible categories/products and stacking rules.
- [ ] Define giveaway rules, eligibility, closing date, winner selection and prize collection method.
- [ ] Confirm which customer contact channel may be used for marketing (email, WhatsApp or both) and collect explicit opt-in before sending promotions.

## 7. Owner admin account

- [ ] Provide the owner's admin email address when the authentication provider is chosen.
- [ ] Choose an MFA method (authenticator app recommended).
- [ ] The owner will create/set their password directly with the authentication provider; no password should be sent in chat.
- [ ] Confirm there will be exactly one admin account and no staff accounts.

## 8. Store content and policies

- [ ] Confirm tagline (current suggested line: “Your next laptop. Expert care. One local team.”).
- [ ] Confirm the phone/WhatsApp number remains 0328 1133770.
- [ ] Confirm address, map pin and opening hours.
- [ ] Provide final About text, repair-service descriptions and any service pricing/diagnostic fee rules.
- [ ] Provide final privacy, terms, delivery, returns and warranty wording for owner/legal review.

## 9. Production launch

- [ ] Confirm domain name and who controls its DNS.
- [ ] Create a separate production backend project after development testing.
- [ ] Decide backup/retention needs for database and uploaded photos.
- [ ] Approve final launch checklist only after security, payment/order and device tests pass.
